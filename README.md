# TRIPLY

AIによる旅程調整、地図、ホテル予約導線、実在モデルコースを一画面に統合した静的Webアプリです。

## 使い方

`index.html` をブラウザで開くだけで利用できます。外部ライブラリとして Leaflet と OpenStreetMap を使用しています。

## 主な機能

- 札幌・小樽の2日間モデルコース
- 旅程と連動するインタラクティブ地図
- 旅のスタイル・希望条件を反映するAI調整UI
- 楽天トラベル・Booking.comへのホテル予約導線

## 公開前に行うこと

予約リンクを収益化する場合は、各アフィリエイトプログラムで発行されたリンクに `app.js` のホテルURLを差し替えてください。
